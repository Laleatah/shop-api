# Shop API Backend

Тестовое задание: CRUD для клиентов, товаров и заказов + база данных.

## Стек технологий:
* Python (FastAPI)
* SQLAlchemy (SQLite)

## Как запустить локально:
1. Установить зависимости: `pip install fastapi uvicorn sqlalchemy`
2. Запустить сервер: `python -m uvicorn main:app --reload`
3. Открыть документацию (Swagger): `http://127.0.0.1:8000/docs`
